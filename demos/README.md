## 如何录制

### 推荐工具

1. **LICEcap** (Windows/Mac) - 轻量级 GIF 录制
2. **Kap** (Mac) - 开源 GIF 录制
3. **Peek** (Linux) - 简单易用
4. **OBS Studio** - 专业录屏，可导出 GIF

### 录制建议

1. 使用 1280x720 或 1920x1080 分辨率
2. 录制 5-10 秒的短视频
3. 突出核心功能
4. 保持画面简洁

### 优化 GIF

```bash
# 使用 gifsicle 优化 GIF 大小
gifsicle -O3 --colors 256 input.gif -o output.gif
```
